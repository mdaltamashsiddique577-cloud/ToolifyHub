# ToolifyHub

All your tools, one simple place. Free browser tools with no login.

## Status

| Area | State |
| --- | --- |
| Pure tool logic (text, calculators, JSON, Base64) | Written and tested (22 tests) |
| Image, PDF, QR and AI tools | Not started |
| Next.js app, pages, SEO, design | Not started |

## Run the tests

```bash
npm test
```

Needs Node 22.6 or newer. The tests run TypeScript directly, so no build step is needed.
